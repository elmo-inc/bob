# bob, the compiler

This is **Bob**. Bob is a compiler.
Bob compiles **Bobol**, the Bob-oriented programming language.

Naturally, Bobol was created by Bob.
This is not a coincidence.

## What is Bob?

Bob takes Bobol source code and turns it into something a computer can understand.

At least, that's what Bob says.

You may be wondering why anyone would make an entire programming language centered around Bob.

You may also be wondering why Bob needs his own compiler.

These are reasonable questions. Bob has no answers.

Bob was not programmed to answer questions.
Bob was programmed to compile Bobol.

## What is Bobol?

Bobol is a programming language designed around one simple principle:

**Everything should be about Bob.**

Bob agrees with this principle.

Bobol agrees with Bob.

Bob compiles Bobol.

It's a very healthy relationship.
